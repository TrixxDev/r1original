# ПРОСТОЕ РЕШЕНИЕ - Блокировка слотов без WebSocket

## Как работает сейчас:

1. Пользователь кликает на `.free-slot-link` или `.available-slot`
2. Открывается форма записи
3. Пользователь заполняет и отправляет
4. **ПРОБЛЕМА:** Другой пользователь может кликнуть на тот же слот одновременно

## Простое решение:

1. При клике на слот → AJAX проверка доступности
2. Если свободен → временная резервация (5 мин) + открыть форму
3. Если занят → показать модальное окно "Выберите другое время"
4. При отправке формы → финальная проверка + запись

В `app/Http/Controllers/Records/RecordController.php` метод `fillSlot`:

```php
public function fillSlot(Request $request)
{
    // ... существующая валидация ...
    
    // НОВЫЙ КОД: Проверка версии слота
    $slotId = $request->input('slot_id');
    $expectedVersion = $request->input('version');
    
    DB::beginTransaction();
    
    try {
        // Получаем слот с блокировкой
        $slot = Slot::where('slot_id', $slotId)
            ->lockForUpdate()
            ->first();
        
        if (!$slot) {
            DB::rollBack();
            return json_encode([
                'success' => false,
                'alertMessage' => 'Слот не найден'
            ]);
        }
        
        // Проверка версии (защита от race condition)
        if ($slot->version != $expectedVersion) {
            DB::rollBack();
            return json_encode([
                'success' => false,
                'alertMessage' => 'Слот был изменен. Обновите страницу.'
            ]);
        }
        
        // Проверка что слот еще свободен
        if ($slot->status == 1 && !empty($slot->takenby)) {
            DB::rollBack();
            return json_encode([
                'success' => false,
                'alertMessage' => 'Извините, этот слот уже занят!'
            ]);
        }
        
        // Сохраняем запись
        $slot->status = 1;
        $slot->takenby = json_encode($result);

        $slot->createuser = $userID;

        // Очищаем резервацию
        $slot->reserved_until = null;
        $slot->reserved_by = null;

        DB::commit();

            'success' => false,

        ]);
    }
}
```

## Что происходит:

```
Пользователь 1 кликает
    ↓
AJAX → /pieraksts/reserve-slot
    ↓
Сервер: reserved_until = now + 5 мин
    ↓
Ответ: { success: true, slot_id, version }
    ↓
Открывается форма + таймер
    ↓
Пользователь 2 кликает на тот же слот
    ↓
AJAX → /pieraksts/reserve-slot
    ↓
Сервер: Слот уже зарезервирован!
    ↓
Ответ: { success: false, message: "..." }
    ↓
Показывается модальное окно "Слот занят"
```

## Дополнительно

### Автоочистка истекших резерваций

В `app/Console/Kernel.php`:

```php
protected function schedule(Schedule $schedule)
{
    $schedule->call(function () {
        \App\Models\Slot::where('reserved_until', '<', now())
            ->whereNotNull('reserved_until')
            ->update([
                'reserved_until' => null,
                'reserved_by' => null
            ]);
    })->everyMinute();
}
```

Запустить:
```bash
php artisan schedule:work
```

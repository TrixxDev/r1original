# Карта функционала R1 Riepas

Карта построена по маршрутам (`routes/web.php`, `routes/api.php`), контроллерам и middleware.
Связанные документы: [БИЗНЕС_ЛОГИКА.md](БИЗНЕС_ЛОГИКА.md), [БАЗА_ДАННЫХ.md](БАЗА_ДАННЫХ.md).

## Модули верхнего уровня

```
R1 Riepas
├── 1. Каталог товаров (публичный)
│   ├── Автошины: зимние /ziemas-riepas, летние /vasaras-riepas
│   ├── Мотошины /motociklu-riepas
│   ├── Квадрошины /kvadru-riepas
│   ├── Промышленные шины /lielas-riepas
│   ├── Диски: /lietie-diski, /kvadru-diski, /kvadraciklu-diski (ATV)
│   ├── Шипы /radzes
│   ├── Акции /akcijas
│   └── Хаб брендов /riepu-razotaji
├── 2. Корзина и заказы (e-commerce)
│   ├── Корзина /shop, /grozs
│   ├── Оформление /credentials → /checkout (/pasutijums)
│   ├── Оплата Paysera (callback /callback)
│   ├── Быстрый заказ /quick-order (Accrual)
│   └── Счета предоплаты /prepayment-invoice/*
├── 3. Запись на услуги (pieraksts)
│   ├── Календарь слотов /pieraksts
│   ├── Блокировка слотов (reserve/extend/cancel/check)
│   ├── Бронирование fillSlot + уведомления (email/SMS/WhatsApp/WS)
│   ├── Отмена /pieraksts/cancel={id}
│   └── Рабочие времена /pieraksts/darba-laiki (auth)
├── 4. Личный кабинет /my-account (auth + verified)
├── 5. Админ-панель /admin (роль administrators)
│   ├── Dashboard и аудит
│   ├── Товары: шины/диски/шипы + бренды + протекторы + импорт
│   ├── Заказы и записи (pieraksts/rezervacijas)
│   ├── Настройки: услуги, пользователи, роли, CMS-страницы,
│   │   баннеры, коды шин, цены, промокоды, сезон, синхронизации
│   └── Управление слотами в realtime (WebSocket)
├── 6. Синхронизация поставщиков /sync/* (Accrual, I3, Goodyear, RZ, RG, Duell, Starco)
├── 7. API
│   ├── Mobile API мастеров /api/v1/mobile/* (Bearer-токен)
│   ├── CarInfo /api/car-info (домен + токен)
│   ├── Lursoft /api/company/{code}
│   ├── Колёса/размеры /api/wheels/*
│   └── Зарплаты /api/get-salaries и др. (MSSQL, auth:api)
└── 8. Маркетинг и SEO
    ├── Google Merchant feed /marketing/feed/google.xml
    ├── Salidzini /xml/salidzini, Kurpirkt /xml/kurpirkt
    ├── Sitemap /sitemap.xml, /robots.txt
    └── Локализация /lang/{lang}
```

## 3. Запись на услуги (pieraksts)

Публичные (middleware `checksession`, `/pieraksts` — ещё и `no.cache`):

| Маршрут | Контроллер@метод | Назначение |
|---|---|---|

| POST `/pieraksts/getSlotInfo` | `@getSlotInfo` | Инфо о слоте |

| POST `/pieraksts/showMobileQueues` | `@showMobileQueues` | Очереди (мобильная вёрстка) |

## 4. Личный кабинет (`auth + verified`)

`/my-account` — обзор; `/my-account/identity[/update]` — личные данные и пароль;
`/my-account/address[/update]` — адрес доставки; `/my-account/history[/{id}]` — история заказов;
`/my-account/order-slip` — счёт. Контроллер: `UserController`.

Аутентификация: `POST /login`, `GET /logout`, сброс пароля `/password/*`.
Регистрация отключена (`register=false`).

## 5. Админ-панель (`auth` + роль `administrators`, при отсутствии — 404)

### Dashboard и аудит
- `GET /admin/` — статистика; `GET /admin/dashboard/data` — данные графиков.
- `GET /admin/audits`, `/admin/audit/{id}` — журнал действий.
- `POST /admin/changeSeason` — переключение сезона сайта (лето/зима).

### Товары (одинаковая структура для auto / moto / quadr / big / rims / quadrims / studs)
На примере автошин (`Admin\AutoTireController`):
- `/admin/auto` — список/поиск; `edit/{id}`, `delete/{id}` — правка/удаление шины;
- `/admin/auto/tread/{id}` — шины протектора: `create`, `store`, `delete`, `image` (фото);
- AJAX: `ajaxUpdateTreads`, `ajaxUpdateTires`, `toggleTop` (акционный флаг);
- `/admin/brands/auto/...` — CRUD + поиск брендов;
- `/admin/treads/auto/...` — CRUD + поиск протекторов (моделей);
- `/admin/import/auto` — импорт из файла (аналогично moto/quadr/big; ATV-диски — импорт Duell).

### Заказы и записи
- `/admin/orders` (+`print`, `search`, `logs`) — заказы магазина; `/admin/order/{id}` (+`update`, `delete`).
- `/admin/pieraksts` (+`date={date}`, `queue_ajax`, `slot_ajax`, `discount`) — управление записями.
- `/admin/rezervacijas` (+`editSlot`) — резервирования.

### Настройки (`Admin\SettingsController`, `RoleController`, `BannerController`, `PromoCodeController`)
- Услуги: CRUD + enable/active (привязка к категориям).
- Пользователи-админы: CRUD, смена статуса и пароля.
- Роли/разрешения (Spatie): CRUD ролей, togglePermission.
- CMS-страницы: CRUD (`pages`).
- Баннеры: upload/update/enable/delete.
- Коды шин (объяснения): CRUD.
- Цены услуг (монтаж/доставка): просмотр + обновление.
- Промокоды: CRUD.
- `/admin/settings/syncs` — страница синхронизаций.

## 7. API

### Mobile API мастеров (`/api/v1/mobile/*`, Bearer `MOBILE_API_TOKEN`)
- `GET lift-spots` — подъёмники; `GET slots` — записи на дату; `GET services` — услуги;
- `POST slots/{id}/update | ic-status | planned-tasks | client-data` — статусы работы, техконтроль, задачи, данные клиента;
- `GET/PUT office-prefs` — настройки филиала (`lift_slot_count`).

### Прочее
- `POST /api/car-info` — данные авто по VIN/номеру (`restrict.domain` + `require.car.info.token`).
- `GET /api/{branch}/slots/`, `/api/slots/{id}`, `/api/search/slot`, `/api/lift-spots`, `/api/services-list` — слоты для интеграций.
- `GET /api/mssql-test`, `find-person`, `get-salaries`, `get-sick-leaves`, `get-salary-status`, `get-complete-report` — зарплатный модуль (MSSQL, `auth:api`).

## 8. SEO / маркетинг
- `GET /robots.txt`, `/sitemap.xml`, `/sitemap-{page}.xml` — `SitemapController` (генерация по крону 03:00).
- `GET /marketing/feed/google.xml` — Google Merchant.
- `GET /xml/salidzini`, `/xml/kurpirkt` — прайс-агрегаторы.

## Middleware

| Middleware | Назначение |
|---|---|
| `auth` / `guest` / `verified` | стандартная аутентификация, верификация email |
| `admin` (`RedirectIfNotAdmin`) | роль `administrators`, иначе 404 |
| `checksession` (`CheckSession`) | проверка сессии/корзины (большей частью отключена) |
| `checkcart` (`CheckCart`) | наличие активного заказа, удаление истёкших (`delete_at < now`) |
| `restrict.domain` | проверка Origin/Referer для API |
| `require.car.info.token` | заголовок X-Car-Info-Token (CarInfo API) |
| `mobile.token` | Bearer-токен мобильного API |
| `no.cache` | запрет кеширования (/pieraksts) |
| `Localization` | локаль из сессии (lv/ru/en) |
| `SessionExpired` | контроль истечения сессии |
| `RequestTimingDebug` / `SessionTimingDebug` | замер времени (debug) |

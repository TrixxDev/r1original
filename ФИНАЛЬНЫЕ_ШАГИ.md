## 2. Обновить RecordController

Открыть файл: `app/Http/Controllers/Records/RecordController.php`

Найти метод `fillSlot` и в начале метода (после валидации) добавить:

```php
use Illuminate\Support\Facades\DB;

// Получаем данные резервации
$slotId = $request->input('slot_id');
$expectedVersion = $request->input('version');

if (!$slotId || !$expectedVersion) {
    return json_encode([
        'success' => false,
        'alertMessage' => 'Ошибка: отсутствуют данные резервации'
    ]);
}

DB::beginTransaction();

try {
    // Получаем слот с блокировкой
    $slot = Slot::where('slot_id', $slotId)
        ->lockForUpdate()
        ->first();
    
    if (!$slot) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Слот не найден'
        ]);
    }
    
    // Проверка версии
    if ($slot->version != $expectedVersion) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Слот уже занят или изменен!'
        ]);
    }
    
    // Проверка резервации
    if ($slot->reserved_by !== session()->getId()) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Время резервации истекло'
        ]);
    }
    
    // ... ЗДЕСЬ ВЕСЬ СУЩЕСТВУЮЩИЙ КОД СОХРАНЕНИЯ ...
    
    // ВАЖНО: Перед $slot->save() добавить:
    $slot->version++;
    $slot->reserved_until = null;
    $slot->reserved_by = null;
    
    $slot->save();
    DB::commit();
    
    // ... остальной код ...
    
} catch (\Exception $e) {
    DB::rollBack();
    \Log::error('Ошибка создания записи: ' . $e->getMessage());
    return json_encode([
        'success' => false,
        'alertMessage' => 'Ошибка создания записи'
    ]);
}
```

## 🎉 Готово к тестированию!

### Как тестировать:

1. Открыть сайт в 2 браузерах (Chrome + Firefox или обычный + инкогнито)
2. В первом браузере кликнуть на свободный слот
3. Должна открыться форма записи
4. Во втором браузере кликнуть на тот же слот
5. Должно появиться модальное окно: "Слот занят"

### Проверка таймера:

1. Кликнуть на слот
2. Подождать 4:30 (4 минуты 30 секунд)
3. Должно появиться предупреждение: "Jūsu sesija beigsies pēc 00:30 sekundēm"
4. Нажать "Turpināt" - резервация продлится на 5 минут
5. Или нажать "Iziet" - форма закроется

### Проверка истечения:

1. Кликнуть на слот
2. Подождать 5 минут
3. Должно появиться: "Jūsu sesija internetbankā ir beigusies..."
4. Нажать "Labi" - страница перезагрузится

## 🐛 Troubleshooting:

### Ошибка 404 на /pieraksts/reserve-slot
```bash
php artisan route:clear
php artisan cache:clear
```

### Ошибка "Class SlotLockingController not found"
Проверить namespace в контроллере:
```php
namespace App\Http\Controllers\Records;
```

### Ошибка "Column 'version' not found"
Запустить миграцию:
```bash
php artisan migrate
```

### JavaScript не загружается
Проверить что файл существует:
```bash
dir public\js\simple-slot-lock.js
```

### Модальные окна не появляются
Открыть консоль браузера (F12) и проверить ошибки

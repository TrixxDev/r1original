# 🔒 СИСТЕМА БЛОКИРОВКИ СЛОТОВ ДЛЯ R1 RIEPAS

Защита от race conditions при одновременной записи на один и тот же слот.

```

Оба отправляют форму → ДВОЙНАЯ ЗАПИСЬ! ❌
```

**После внедрения:**
```
Пользователь 1 кликает на слот 10:00 → Резервация → Форма

```

## ⚡ БЫСТРЫЙ СТАРТ (5 минут)

### 1. Добавить в HTML

В `resources/views/records/index.blade.php` перед `</head>`:

```html
<meta name="csrf-token" content="{{ csrf_token() }}">
<script src="{{ asset('js/simple-slot-lock.js') }}"></script>
```

### 2. Запустить миграцию

```bash
php artisan migrate
```

### 3. Добавить маршруты

В `routes/web.php`:

```php
Route::post('/pieraksts/reserve-slot', [App\Http\Controllers\Records\SlotLockingController::class, 'reserve']);
Route::post('/pieraksts/cancel-reservation', [App\Http\Controllers\Records\SlotLockingController::class, 'cancel']);
```

### 4. Готово!

Откройте 2 браузера и протестируйте.

**Подробная инструкция:** `БЫСТРЫЙ_СТАРТ.md`

## 🛠️ TROUBLESHOOTING

### Проблема: JavaScript не загружается

**Решение:**
```bash
# Проверить что файл существует
ls public/js/simple-slot-lock.js

# Очистить кеш
php artisan cache:clear
```

### Проблема: Миграция не выполняется

**Решение:**
```bash
# Проверить статус
php artisan migrate:status

# Выполнить миграцию
php artisan migrate

# Откатить и выполнить заново
php artisan migrate:rollback
php artisan migrate
```

### Проблема: Слот не резервируется

**Решение:**
1. Открыть консоль браузера (F12)
2. Проверить ошибки JavaScript
3. Проверить что CSRF token присутствует
4. Проверить маршруты: `php artisan route:list | grep reserve`

## 🔧 Что нужно сделать:

### 1. Запустить миграцию (1 мин)

```bash
php artisan migrate
```

Это добавит поля в таблицу `slots`:
- `reserved_until` - время истечения резервации
- `reserved_by` - кто зарезервировал (session_id)
- `version` - версия для оптимистичной блокировки

### 2. Обновить RecordController (2 мин)

В `app/Http/Controllers/Records/RecordController.php` в методе `fillSlot` найти:

```php
$slot = Slot::where('date', $dopParams['date'])
    ->where('queue_id', $dopParams['queue_id'])
    ->where('iorder', $dopParams['iorder'])
    ->first();
```

Заменить на:

```php
use Illuminate\Support\Facades\DB;

// В начале метода получаем данные резервации
$slotId = $request->input('slot_id');
$expectedVersion = $request->input('version');

if (!$slotId || !$expectedVersion) {
    return json_encode([
        'success' => false,
        'alertMessage' => 'Ошибка: отсутствуют данные резервации'
    ]);
}

DB::beginTransaction();

try {
    // Получаем слот с блокировкой
    $slot = Slot::where('slot_id', $slotId)
        ->lockForUpdate()
        ->first();
    
    if (!$slot) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Слот не найден'
        ]);
    }
    
    // Проверка версии (защита от race conditions)
    if ($slot->version != $expectedVersion) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Слот уже занят или изменен другим пользователем!'
        ]);
    }
    
    // Проверка резервации
    if ($slot->reserved_by !== session()->getId()) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Время резервации истекло'
        ]);
    }
    
    // ... остальной код сохранения записи ...
    
    // ВАЖНО: Добавить эти строки перед $slot->save()
    $slot->version++; // Увеличиваем версию
    $slot->reserved_until = null; // Очищаем резервацию
    $slot->reserved_by = null;
    
    $slot->save();
    DB::commit();
    
    // ... остальной код ...
    
} catch (\Exception $e) {
    DB::rollBack();
    \Log::error('Ошибка создания записи: ' . $e->getMessage());
    return json_encode([
        'success' => false,
        'alertMessage' => 'Ошибка создания записи'
    ]);
}
```

## 🐛 Если что-то не работает:

1. **Проверить консоль браузера (F12)**
   - Должно быть: "✅ Simple Slot Lock инициализирован"
   - Не должно быть ошибок 404 или 500

2. **Проверить что миграция выполнена:**
   ```bash
   php artisan migrate:status
   ```

3. **Проверить что файл загружается:**
   - Открыть: `http://ваш-сайт/js/simple-slot-lock.js`
   - Должен открыться JavaScript файл

4. **Проверить маршруты:**
   ```bash
   php artisan route:list | findstr "reserve"
   ```
   Должны быть:
   - POST pieraksts/reserve-slot
   - POST pieraksts/extend-reservation
   - POST pieraksts/cancel-reservation

5. **Проверить логи:**
   ```bash
   type storage\logs\laravel.log
   ```

### Шаг 4: Обновить RecordController
В `app/Http/Controllers/Records/RecordController.php` в методе `fillSlot`:

**Найти:**
```php
$slot = Slot::where('date', $dopParams['date'])
    ->where('queue_id', $dopParams['queue_id'])
    ->where('iorder', $dopParams['iorder'])
    ->first();
```

**Заменить на:**
```php
use Illuminate\Support\Facades\DB;

$slotId = $request->input('slot_id');
$expectedVersion = $request->input('version');

if (!$slotId || !$expectedVersion) {
    return json_encode([
        'success' => false,
        'alertMessage' => 'Ошибка: отсутствуют данные резервации'
    ]);
}

DB::beginTransaction();

try {
    $slot = Slot::where('slot_id', $slotId)
        ->lockForUpdate()
        ->first();
    
    if (!$slot) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Слот не найден'
        ]);
    }
    
    if ($slot->version != $expectedVersion) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Слот уже занят или изменен!'
        ]);
    }
    
    if ($slot->reserved_by !== session()->getId()) {
        DB::rollBack();
        return json_encode([
            'success' => false,
            'alertMessage' => 'Время резервации истекло'
        ]);
    }
    
    // ... ЗДЕСЬ ВЕСЬ СУЩЕСТВУЮЩИЙ КОД СОХРАНЕНИЯ ...
    
    // ВАЖНО: Перед $slot->save() добавить:
    $slot->version++;
    $slot->reserved_until = null;
    $slot->reserved_by = null;
    
    $slot->save();
    DB::commit();
    
} catch (\Exception $e) {
    DB::rollBack();
    \Log::error('Ошибка создания записи: ' . $e->getMessage());
    return json_encode([
        'success' => false,
        'alertMessage' => 'Ошибка создания записи'
    ]);
}
```
